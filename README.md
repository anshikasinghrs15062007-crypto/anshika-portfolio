# 📊 Business Health Analyzer

> An end-to-end interactive Business Intelligence application designed to analyze company financial health, calculate core operational KPIs, and generate automated AI recommendations using the Claude API.

## 📌 Overview

The **Business Health Analyzer** bridges data analytics and executive decision-making. It evaluates raw business metrics across revenue, operating costs, and unit economics to assess whether an enterprise is operating at healthy profit margins or trending toward a loss.

In addition to calculating key financial metrics, the application leverages an embedded **Claude API** to turn raw computed numbers into executive-level written insights and strategic recommendations.

---

## 🚀 Key Features

- **Dynamic KPI Computation:** Real-time calculation of Gross Revenue, Operating Margin, Cost of Goods Sold (COGS), and Net Profitability.
- **Relational Data Modeling:** Structured schema querying revenue, inventory, and cost tables using optimized SQL queries.
- **DAX & Formula Validation:** Embedded DAX measure logic to drive precise metric aggregations across operational units.
- **AI-Powered Insights:** Integrated Claude API that ingests computed numbers and generates action-oriented business recommendations.
- **Responsive Dashboard UI:** Clean, interactive front-end built with HTML5, CSS3 (Tailwind CSS), TypeScript, and JavaScript.

## 📐 Data Architecture & Methodology

1. **Data Ingestion & Cleaning:** Standardized multi-source data tables using structured transformation pipelines.
2. **KPI Modeling:** Defined formulas for profitability margins, expense ratios, and revenue growth indicators.
3. **Validation Layer:** Verified AI-generated written recommendations against raw underlying datasets to ensure analytical accuracy.
